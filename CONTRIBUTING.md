# Contributing to SpiddyWeb

Thank you for considering contributing to **SpiddyWeb**! 🕷️✨

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub Issues. Before creating a bug report, please check the existing issues.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure Python code adheres to Django best practices.
3. Test your changes locally (`python manage.py test` or `python manage.py check`).
4. Issue a Pull Request with a detailed summary of your changes.

---

Thank you for helping make SpiddyWeb better!
