🚀 User Guide & Features

1. Uploading Files: Select single or multiple files (up to 2GB total) or drag & drop them into the Web Drop Zone. Multiple files are automatically bundled into a single ZIP drop.

2. PIN & QR Sharing: Every upload generates a unique 6-digit PIN and direct share link + mobile QR code.

3. Passcode Protection: Optionally set a secret password during upload for extra security.

4. Auto Self-Destruct: Choose auto-expiry (1hr, 6hr, 24hr, 7 days) or One-Time Download mode (deletes immediately after first retrieval).

⚡ REST API Reference

POST /upload/
Form Data: file, filename, chunk_index, total_chunks, upload_id, expires_hours, password (optional)
Initiates or appends a 2MB chunk to a File Drop. Returns JSON success with PIN on last chunk.
POST /receive/
Form Data: pin, password (optional)
Validates PIN & password, returning file metadata, download count, and remaining expiry milliseconds.
GET /file/{pin}/download/
Query Params: password (optional)
Streams raw file binary attachment. Increments download counter and purges file if One-Time mode is active.

🛡️ Security & Limits

Max File Limit
2 GB per drop. Chunked JS streaming prevents memory crashes.
Bandwidth Limit
5 GB per IP per hour & 10 uploads per hour max.
Brute Force Protection
5 failed PIN attempts trigger 15-minute IP lockout.
Extension Blacklist
Executable and script files (.exe, .bat, .sh, .vbs) are blocked.
